# たんぱく質ノート

1日のたんぱく質量を記録するスマホ向けWebツール（PWA）です。

- 年齢・性別から、1日の**推奨量**を表示します（日本人の食事摂取基準2025年版）
- 体重を入れると参考値も表示します（18歳以上は体重からの参考値、65歳以上はフレイル予防の参考量 1.2g/kg）
- 食材とグラム数を入れると、たんぱく質量を計算します（日本食品標準成分表 八訂増補2023年・2,537食品）
- 食事ごとの記録、履歴（14日グラフ）、マイ食品、前日コピー、「あと◯gをとるなら」の提案があります
- データは端末のブラウザ（localStorage）だけに保存されます。サーバーには送信しません。バックアップの書き出し・復元ができます
- ホーム画面に追加すると、オフラインでも動きます

## 公開手順（GitHub → Vercel）

1. このフォルダの中身をそのままGitHubの新しいリポジトリに入れる（ビルド不要の静的ファイル）
2. VercelでそのリポジトリをImport。Framework Preset は **Other**、Build Command・Output Directory は空欄のままDeploy
3. 発行されたURLをスマホで開き、「ホーム画面に追加」

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html / style.css / app.js | アプリ本体 |
| foods.json | 成分表から作った食品データ（食品番号・食品群・食品名・100gあたりたんぱく質・推定値フラグ・100mLあたりの重さ） |
| sw.js | オフライン用。**ファイルを更新したら `VERSION` を上げる**（上げないと古い版が表示され続けます） |
| manifest.webmanifest / icons/ | ホーム画面用の設定とアイコン |
| tools/build_foods.py | 成分表Excelから foods.json を作り直すスクリプト |

## マイリスト（利用者が自分で作る）

よく食べるものを利用者が自分で登録し、追加画面からタップ1回で記録できる。配布側で用意するものはない。

- 食材：記録するときの「☆ この量でマイリストへ」で、量ごと保存（例：卵1個 50g）
- 市販品：パッケージの栄養成分表示から登録。「1個・1本などあたり」か「100gあたり」を選ぶ（入力画面に見本つき）
- メニュー：1食あたりのたんぱく質を数字で登録（外食の栄養表示など）
- 検索で見つからないときは、その語のまま「マイリストに登録」へ進める
- 入力チェック：100gあたりで100g超は登録不可、1個あたり80g超・メニュー100g超は確認を出す
- 旧版（v1.1以前）の「マイ食品」は、初回起動時に自動でマイリスト（市販品）へ移る

## 数値の根拠

- **推奨量・推定平均必要量**：厚生労働省「日本人の食事摂取基準（2025年版）」策定検討会報告書 各論1-2 たんぱく質 p.103の表
- **体重からの参考値**：維持必要量 0.73g/kg体重/日（p.90）× 推奨量算定係数 1.25（p.92）。切上げ。妊娠・授乳中は付加量を加算
- **フレイル予防の参考**：65歳以上で 1.2g/kg体重/日（p.95。「予防できる可能性がある」という記述で、基準値ではない）
- **妊婦・授乳婦の付加量**：中期+5g、後期+25g、授乳中+20g（p.103）
- **食品の値**：日本食品標準成分表（八訂）増補2023年から引用。文部科学省の2026年3月27日掲載Excel「第2章（データ）」の「たんぱく質」列（PROT-）を使用（正誤表の内容は反映済み）。括弧付きの値は推定値、Trは0として扱う
- **目安量（卵1個＝50gなど）**：このツール独自の一般的な目安で、公的な値ではない（アプリ内にもそう表示）。牛乳200mL＝206.4gは成分表の備考（100mL＝103.2g）から計算

成分表は文部科学省が自由に利用できるデータとして公開しています。二次利用するときは「日本食品標準成分表（八訂）増補2023年から引用」と出典を書く必要があります。この表示はアプリ内に入れてあるので、消さないでください。

## 成分表が改訂されたとき

```
python3 tools/build_foods.py <新しいExcel> foods.json
```
列の位置が変わっている場合はスクリプトが止まります。そのときはスクリプトを修正してください。最後に `sw.js` の `VERSION` を上げます。
